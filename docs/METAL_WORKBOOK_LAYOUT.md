# 금속 누적표와 보고서 분리

2026-10-27 사용자 사진을 기준으로 이해한 구조입니다. 사진의 흐린 글자를
정확한 종목·가격 코드로 확정하지 않습니다. 원본 Excel이나 헤더 텍스트가
확인되기 전 기존 사용자 시트/열/수식을 재배치하지 않습니다.

## 사진의 구조

- 왼쪽: 연·월·일 날짜. 한 고시일에 한 행을 계속 추가합니다.
- 중간: 탄산리튬 → 수산화리튬 → 니켈 → 코발트 → 구리.
- 각 금속은 FMB·SMM·GFEX·LME 등 출처/조건별로 **서로 다른 고정 열**입니다.
- 이어서 Black Mass Payable (NCM/NCA, LCO 등), 오른쪽에 달러·위안화 등 환율.
- 세부 중국 조건/Payable 하위 품목/마지막 환율 헤더는 사진만으로 확정하지 않았습니다.

날짜를 행으로 누적하고 품목×출처×단위×모드×뷰를 열의 식별자로 유지합니다.
현재 `일별시세`는 ISO 날짜 1열 + 품목 헤더 1행 + 원천 기준 1행 구조이며
원본 DB와 `가격열설정`을 유지합니다. 사진의 연·월·일 3열은 향후 회사 양식
매핑으로 제공할 수 있지만, 현재 운영 시트를 사진만 보고 덮어쓰지 않습니다.

## 적용한 구분

1. SQLite: 모든 검증된 금속/환율/공개 시장 원자료·수정 이력을 보존.
2. 운영 누적 Excel/ECM: 금속·환율만. 신규 NAVER/FDR 가격 열·시장 보고 시트는
   추가하지 않습니다. 예전에 만들어진 시트/사용자 열은 삭제하지 않습니다.
3. 별도 보고용 Excel·HTML·PPTX: 주가·지수·시총과 금속/환율 요약을 포함.
4. 첫 화면: 금속·환율 중심. 시장/주가/시총은 자료·보고서 화면에서만 표시.
5. 금속 표의 반복 출처 열은 화면에서 숨깁니다. 원본 검증·출력용 출처는 보존.

## 수집 기준

- 오전 08:30: KST 오늘 미만의 실제 일별 종가 두 날짜를 사용. 전일대비에서 역산하지 않음.
- 서로 다른 품위/지역/인도조건/선물 만기/원천을 자동 대체하지 않음.
- LME 공개 Official Cash/3-month의 Ask 6열은 금속 운영표에 누적합니다.
  Cash Ask는 공식 Settlement이며 FMB Mid로 취급하지 않습니다.
- LME 기타 계약/Closing·SMM·GFEX 미지원 항목은 FMB 값으로 채우지 않습니다.
- 시총 실시간 랭킹에는 거래 기준일이 없어 수집시점 원자료로 저장.
  시총 비교는 서로 다른 수집일의 스냅샷 비교이며 확정 전일/전전일 시총이 아님.
  첫날은 `missing_prior_capture`. 과거 시총을 주가로 역산하지 않음.

원본 Excel 또는 복사한 정확한 헤더와 단위·종목 코드가 있으면 고정 열 매핑을
검증할 수 있습니다. 사진만으로 이 매핑이 완성됐다고 주장하지 않습니다.
