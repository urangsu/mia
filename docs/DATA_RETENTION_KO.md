# 프로그램 교체와 자료 보존

설치 폴더를 삭제해도 자료가 유지되려면 실제 설정의 `data_dir`가 설치 폴더 밖이어야 한다.
코드의 기존 기본값은 `%USERPROFILE%\Documents\FastmarketsCollector`다. 기존 사용자 설정은
덮어쓰지 않는다. 회사 계정에서는 `C:\Users\POSCOHYCM\Documents\FastmarketsCollector`를
권장한다. 설정 화면의 데이터 폴더·누적 Excel·보고서 폴더 세 항목을 확인한다.

## 누적 원본과 재생성 가능한 출력

- `fastmarkets_prices_v3.sqlite3`: 수집 원본 DB. Fastmarkets 가격/정정, 환율,
  NAVER 지표/시총 스냅샷, LME, SMM, 선택 FDR 자료는 각 저장 단계 성공 시 DB에 쓴다.
- Excel·CSV·HTML·PPTX: 저장된 DB를 이용한 출력. 수집 실패·미검증 값이 DB에
  모두 정상 가격으로 저장된다는 뜻은 아니다. 실제 날짜·건수·오류 상태를 확인한다.
- 수기 입력 Excel·수식·매크로·ECM 문서·별도 수입 CSV: DB의 사본이 아니다.
  DB만 백업해서 이 파일들까지 복구할 수 있다고 가정하지 않는다.
- `config.json` 및 Chrome 9444 프로필은 `%LOCALAPPDATA%\FastmarketsCollector`에
  별도 보관된다. 로그인 프로필·쿠키·토큰은 공개 저장소/반입 TXT에 넣지 않는다.

## 교체 순서

1. 앱과 기존 예약 작업을 중지한다. 업데이트 폴더 안을 실제 데이터 위치로 썼다면
   삭제 전에 데이터 폴더 전체를 별도 백업한다. SQLite -wal/-shm도 임의 삭제하지 않는다.
2. 기존 프로그램 폴더는 삭제 대신 이름을 바꿔 보관한다. 복원기는 기존 폴더를 덮어쓰지 않는다.
3. 같은 위치에 최신 TXT/PY를 놓고 새 `MIA_Collector_Update`를 복원한다.
4. 설정의 실제 데이터 위치를 확인한다. 경로 변경은 이력을 이동/합치는 기능이 아니다.
5. 수집 전 기존 최근 날짜·대표 값·건수를 확인하고, TEST 문서로 출력만 먼저 검증한다.
6. DB 백업과 출력 재생성 검증 뒤, 자동 생성 출력만 선택적으로 정리할 수 있다.
   파일 삭제는 자동 수행하지 않으며 사용자 내용이 있는 문서는 정리 대상에서 제외한다.

이 문서는 코드의 저장 경로/SQLite 경로를 확인한 안내이며 회사 PC에 현재 있는
DB의 무결성·백업 완료를 증명하지 않는다. 프로그램 소스 TXT에는 실제 누적 DB가 없다.
