# MIA DOM Inspector V4 — Chrome/Edge 확장 프로그램 원본

> 이 폴더는 **Chrome Manifest V3 확장 프로그램**의 소스 묶음 및 안전한 복원 도구입니다. MIA Collector의 Python/Selenium 코드와 **독립적**이며 Chrome CDP 9444/9222/9337, ECM, Excel에 접근하거나 설정을 바꾸지 않습니다.

## 소스 보관 방식

공개 GitHub 저장소의 이 경로에는 검증된 **14개 원본 파일**이 `MIA_DOM_ARCHIVE_V4.txt`(SHA-256 검증 가능한 XZ 타르 아카이브)로 들어 있습니다. 로컬 복원 시 `extension/` 폴더가 생성됩니다. **TXT 자체를 크롬 확장 프로그램으로 선택하면 안 됩니다.** 폴더 안 `manifest.json`을 확인한 다음 설치하세요.

원본은 이전에 사용자에게 제공된 `MIA_DOM_Inspector_V4_미니패널.zip`과 14개 파일을 바이트 단위로 대조해 동일한 것으로 확인했습니다. 테스트 파일 5개도 포함되어 있습니다. 회사 Windows / 실제 업무 사이트에 대한 최종 작동 보증은 아닙니다.

## 설치 — Windows

1. 이 폴더의 `MIA_DOM_ARCHIVE_V4.txt`, `RESTORE_DOM_V4.py`, `RESTORE_DOM_V4.cmd` 세 파일을 **같은 로컬 폴더**에 내려받으세요. 전체 브랜치 ZIP을 받아도 됩니다.
2. 설치된 Python 3에서 `RESTORE_DOM_V4.cmd` 실행 또는 명령 프롬프트에서 다음 명령을 실행하세요.

```powershell
py -3 .\RESTORE_DOM_V4.py --verify-only
py -3 .\RESTORE_DOM_V4.py
```

3. 복원 완료 시 `extension/` 폴더가 생성됩니다. 기존 `extension/`이 있으면 **덮어쓰지 않고 중단**하므로 새 폴더로 복원하려면 `--output "C:\Temp\MIA_DOM_V4_New"`를 지정합니다.
4. Chrome 주소창에 `chrome://extensions` 입력 → **개발자 모드** → **압축해제된 확장 프로그램을 로드합니다** → 복원된 `extension/` 폴더 선택. Edge는 `edge://extensions`.
5. 검사할 사이트의 탭에서 확장 버튼 → **여러 요소 선택 시작 / 이어서 선택**. 오른쪽 위의 **MIA ▸ 펼치기** 버튼은 기본 접힘 상태입니다. 필요한 요소들을 연속 클릭하고, **선택 항목만 JSON 저장**을 누릅니다.

## 주요 기능

- 클릭해서 여러 요소 수집 / 접이식 미니 패널 / 마지막 취소 및 항목 삭제
- 클릭한 요소·표 행·전체 그리드 범위 선택, ↑/↓로 선택 요소 범위 조절
- Fastmarkets AG Grid의 같은 `row-index`에 속한 pinned 날짜/가격 조각 수집
- DOM 구조와 안전한 속성 샘플, JSON 내보내기
- 전체 DOM 스캔은 선택적 기능. 가상 스크롤로 렌더되지 않은 행까지 읽었다고 주장하지 않습니다.

## 보안·운영 주의

- 사내 정책상 개발자 확장 설치가 허용되는 PC에서만 사용하세요. 정책 우회/관리자 권한 획득/프로필 복사 등은 하지 않습니다.
- 선택한 요소에 따라 페이지 본문과 업무상 민감한 내용이 JSON에 포함될 수 있습니다. 실제 데이터 캡처를 **공개 GitHub에 올리지 마세요**.
- 이 폴더에는 회사 데이터·비밀번호·쿠키·시세 수집 JSON을 포함하지 않습니다.
- `chrome://extensions`에서 기존 V2/V3 확장은 충돌 방지를 위해 비활성화하세요.
- GitHub 작업 브랜치에서 준비된 소스이며, main 반영 여부는 연결된 PR 상태를 확인하세요.
