MIA Collector — 현재 반입 안내

GitHub main/bring_in에서 다음만 받습니다.
1. MIA_SOURCE_CURRENT.txt
2. RESTORE_LATEST_SOURCE.py
3. RESTORE_LATEST_SOURCE.cmd (선택)
4. MIA_COMPANY_SETUP_GUIDE_KO.txt (명령·설명)

회사에서는 %APPDATA%\Microsoft\AddIns\vsc\매크로에 바로 두어도 됩니다.
복원 폴더는 MIA_Collector_Update, 실행기는 MIA_Collector.py입니다.
날짜 이름 폴더를 만들거나 TXT를 다른 폴더로 옮길 필요 없습니다.
정확한 복사 명령은 MIA_COMPANY_SETUP_GUIDE_KO.txt 하나에 있습니다.

예전 MIA_COLLECTOR_ONEFILE / PART_01~11 / RESTORE_MIA_FROM_TXT는
bring_in/archive/legacy의 과거 기록이며 현재 설치에 쓰지 않습니다.
기존 운영 폴더·DB·Excel·브라우저 프로필을 지우지 마세요.
TXT 헤더 source_commit과 SHA-256이 실제 포함된 소스의 기준입니다.
