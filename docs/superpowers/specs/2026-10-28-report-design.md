# 금속 중심 보고서 표시 설계

사용자 승인: 2026-10-28. 밝은 기본 화면, 최상단 다크 테마 전환 버튼.

HTML 보고서만 표시 계층을 교체한다. 앱 테마, 브라우저, 수집, DB,
누적 Excel/ECM, 원자료 snapshot과 PPTX의 기존 계약은 유지한다.

금속 → 환율 → 시장지표 → 시총 → 주가 순으로 간결한 표를 표시한다.
종합은 중복을 줄이기 위해 별도 접힘 표로 제공한다. 이름은 안전한 HTTP(S)
원문 링크다. 출처/상태/코드/구분/원문 조건 열은 주 표에서 제거하되 원자료
표와 전체 경고는 맨 마지막 자료 상태 details 안에 보존한다.

고시일/비교일은 실제 날짜가 같은 행끼리 묶어 표 위에서 한 번 표시한다.
시총은 확정 시총과 수집 스냅샷을 구별하며 수집시각은 표 위에 표시한다.
시총 없는 주가 이력은 시총 표에 포함하지 않는다. 가격과 누락은 변경하지 않는다.
등락률과 % 값은 표시할 때만 소수점 한 자리와 %를 붙인다.
주가 원, 시총 억원은 제목에서 표시하며 금속/FX의 서로 다른 단위는
품목 하위 설명에 유지한다. 100 JPY 등 환산 기준을 지우지 않는다.

로컬 시스템 글꼴, 정렬된 숫자, 절제된 적/청 등락색, 그림자 없는 구분선.
일별 수치 보고서이므로 임의 해설·장식 차트를 추가하지 않는다.
모바일에서 수치 비교를 보존하는 표 내부 스크롤은 허용하되 페이지 overflow는 막는다.
오류/원자료는 화면과 인쇄 모두 펼치기 전에는 숨긴다.

검증: 합성 snapshot 불변, 반복 이력 제외, 혼합일 분리, 안전 링크, 퍼센트,
두 테마 전환/저장 차단 fallback, 키보드 focus, 접힘과 모바일 실브라우저 확인.
회사 데이터와 Windows 운영 인수는 이 HTML 합성 검증과 별개다.
