0. 결론: 어디에 두고, 무엇을 가져가나?
============================================================

사용 중인 회사 경로:
%APPDATA%\Microsoft\AddIns\vsc\매크로

이 경로 아래 새 하위 폴더를 만들어 사용하는 것은 코드상 가능합니다.
한글 경로 자체를 금지하는 로직은 없습니다. 다만 회사의 폴더 실행 권한,
보안 프로그램, Python 패키지 설치/긴 경로 제한까지 이 Mac에서 확인한 것은
아닙니다. AddIns 밑에 두어도 Excel 추가기능으로 자동 설치되는 것은 아닙니다.
Python 프로그램으로 실행해야 합니다. 관리자 권한/보안 우회는 필요하지 않습니다.

아래 폴더는 지우거나 덮어쓰지 마세요.
  MIA_Collector  : 기존 본 프로그램
  MIA_DOM_V4     : 기존 DOM 확장
  MIA_ONEFILE    : 과거 복원 키트

새 반입 폴더:
  매크로\MIA_UPDATE_20261025

새 프로그램 폴더(직접 --output을 지정하여 복원):
  매크로\MIA_Collector_20261025

날짜 20261025는 이번 개선판의 구분명입니다.
오늘 이 안내를 만들었다고 기존 복원본/가상환경을 다시 만들 필요는 없습니다.

반입할 파일 — 필수 2개:
  1) MIA_SOURCE_CURRENT.txt       : 전체 소스를 담은 데이터 TXT
  2) RESTORE_LATEST_SOURCE.py     : 위 TXT 전용 복원 프로그램

선택 파일:
  3) RESTORE_LATEST_SOURCE.cmd    : 기본 경로 복원용 더블클릭 실행기
  4) 이 안내 TXT                 : 회사에서 명령을 확인할 설명서

중요: "단일 TXT"란 전체 소스를 한 TXT에 담았다는 뜻입니다.
TXT를 더블클릭하는 것만으로 프로그램이 설치되지는 않습니다.
복원하려면 전용 PY도 필요합니다. 이 안내 TXT 자체에는 프로그램 소스가 없습니다.

사용하지 않을 구버전:
  MIA_COLLECTOR_ONEFILE.txt
  MIA_COLLECTOR_PART_01.txt ~ PART_11.txt
  RESTORE_MIA_FROM_TXT.py
새 TXT와 과거 ONEFILE/PART용 복원기를 섞지 마세요.

2. PowerShell: 반입 폴더 준비
============================================================

명령은 일반 PowerShell 창에서 블록별로 실행합니다.
복사할 때 제목/설명은 빼고 명령 줄만 복사하세요.
관리자 PowerShell, 실행 정책 해제, Activate.ps1 실행은 필요하지 않습니다.

---- 명령 시작 ----
$root = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로'
$update = Join-Path $root 'MIA_UPDATE_20261025'
$target = Join-Path $root 'MIA_Collector_20261025'

Write-Host "회사 매크로 폴더: $root"
if (-not (Test-Path -LiteralPath $root -PathType Container)) {
    throw '회사 매크로 폴더가 없습니다. 계정/경로를 확인한 뒤 진행하세요.'
}
New-Item -ItemType Directory -Force -Path $update | Out-Null
Set-Location -LiteralPath $update
Get-ChildItem -Name
---- 명령 끝 ----

현재 로그인 계정에서는 $root가 위 0번의 경로로 표시되어야 합니다.
위 명령은 폴더만 준비합니다. GitHub 파일을 자동 다운로드하지 않습니다.
이제 필수 TXT/PY와 선택 CMD를 MIA_UPDATE_20261025에 넣으세요.
파일 이름이 .txt.txt / .py.txt로 이중 저장되지 않았는지 확인하세요.

---- 명령 시작 ----
Get-Item -LiteralPath '.\MIA_SOURCE_CURRENT.txt', '.\RESTORE_LATEST_SOURCE.py' |
    Select-Object Name, Length
py -3 --version
py -3 -c "import sys; assert sys.version_info >= (3,10), 'Python 3.10+ required'; print(sys.executable)"
if ($LASTEXITCODE -ne 0) { throw '회사 승인 Python 3.10 이상을 먼저 확인하세요.' }
---- 명령 끝 ----

py가 없거나 버전이 맞지 않으면 회사에서 승인한 Python 설치/사용 방법을 확인합니다.
필수 라이브러리는 복원 후 설치합니다. 복원기 자체는 Python 표준 라이브러리만 씁니다.

검증에 통과했으면 새 폴더로 복원:

if (Test-Path -LiteralPath $target) {
    throw '복원 대상이 이미 있습니다. 삭제하지 말고 기존 복원본을 쓰거나 새 폴더명을 지정하세요.'

py -3 .\RESTORE_LATEST_SOURCE.py --output "$target"

    (Join-Path $target 'requirements-desktop.txt')

기대 복원 위치:
%APPDATA%\Microsoft\AddIns\vsc\매크로\MIA_Collector_20261025

이미 MIA_Collector_20261025가 있다면:
  - 같은 버전 복원이 끝난 경우에는 4~5번 설치/실행 단계로 넘어갑니다.
  - 별도 복원이 필요하면 $target을 MIA_Collector_20261025_02 등 새 이름으로
    바꿉니다. 이후 실행 명령도 같은 새 이름을 사용하세요.
  - 기존 폴더/DB/Excel을 삭제하거나 강제 덮어쓰지 마세요.

주의: RESTORE_LATEST_SOURCE.cmd를 그냥 더블클릭하거나 --output 없이 복원하면
기본 위치는 아래입니다. 위 매크로 폴더로 자동 복원되지 않습니다.

따라서 말씀하신 회사 위치에 둘 때는 위의 --output 명령을 사용하세요.

5. 첫 실행 전: 설정이 공용이라는 점이 중요합니다
============================================================

프로그램 소스 폴더와 가상환경은 새로 만들었지만, 현재 설정/전용 Chrome 프로필은
사용자 계정 기준 공용 위치를 사용합니다.

설정 파일:
  %LOCALAPPDATA%\FastmarketsCollector\config.json
전용 Fastmarkets Chrome 프로필:
  %LOCALAPPDATA%\FastmarketsCollector\ChromeProfile_9444
설정이 없을 때의 기본 데이터 폴더:
  사용자 홈\Documents\FastmarketsCollector
  (회사에서 실제 문서 폴더를 다른 곳으로 리디렉션했다면 원하는 경로를 직접 지정)

즉, 새 폴더 설치 = 운영 데이터/프로필까지 완전 격리라는 뜻이 아닙니다.
이전 설정의 data_dir, workbook_path, report_dir가 그대로 적용될 수 있습니다.
설정을 저장하면 구버전 실행에도 같은 설정이 적용될 수 있습니다.
테스트 중 구버전 수집기/기존 예약을 동시에 실행하지 마세요. 회사 예약의 활성
여부를 확인하고 필요한 중단은 담당자와 조율하세요.

원한다면 실행 전 현재 설정만 로컬 백업하세요(자동 복원/설정 변경 아님).
이 백업에는 회사 경로가 있을 수 있으므로 공개 Git/외부 채팅에 올리지 마세요.

---- 명령 시작 ----
$config = Join-Path $env:LOCALAPPDATA 'FastmarketsCollector\config.json'
if (Test-Path -LiteralPath $config -PathType Leaf) {
    $backup = Join-Path $update ('config_before_update_' + (Get-Date -Format 'yyyyMMdd_HHmmss') + '.json')
    Copy-Item -LiteralPath $config -Destination $backup -ErrorAction Stop
    Write-Host "설정 사본 저장: $backup"

& $python .\FastmarketsCollector_v3_7.py

GUI에서 수집 버튼을 누르기 전에 확인:

  2) 누적 Excel: 운영 원본이 아닌 시험용 사본
  3) 보고서 폴더: 시험용 별도 경로
  4) 수집할 출처: FMB/환율/NAVER DOM/FDR를 구별

ECM 적용/자동 실행 등록은 첫 검증과 별도 단계입니다. 바로 승인하지 마세요.

7. 공개 종가만 별도 시험하는 선택 명령
============================================================

이 명령은 실제 공개 HTTP 요청 및 시험 폴더 DB/Excel/보고서 쓰기를 수행합니다.
회사에서 허용한 네트워크에서만 실행하세요. Fastmarkets·SMBS·NAVER DOM 수집과
ECM은 실행하지 않습니다. 새 PowerShell 창에서도 실행 가능한 블록입니다.

---- 명령 시작 ----
$root = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로'
$program = Join-Path $root 'MIA_Collector_20261025'

Set-Location -LiteralPath $program
& $python .\FastmarketsCollector_v3_7.py --once --public-only --data-dir "$testData" --workbook "$testExcel" --report-dir "$testReports"
Write-Host "실행 종료 코드: $LASTEXITCODE"
---- 명령 끝 ----

현재 한국10년(KR10Y)이 미지원이므로 다른 공개 종가를 저장했어도 종료 코드 2 /
