# 기존 금속시세TEST.xlsm 입력

## 이번 입력 기준

- 기존 일반 Edge의 ECM 로그인 세션에서 대상 파일을 연다. 다른 관리자 Edge나 디버그 포트 9222·9337을 조작하지 않는다.
- 설정의 ECM 파일명은 `금속시세TEST.xlsm`, 검색어는 `금속시세TEST`로 지정한다.
- 기존 `금속시세` 시트를 사용한다. 1행 품목명 + 3행 출처로 열을 찾고, 필요한 경우 2행 세부조건으로 구분한다.
- A3/B3/C3는 연도/월/일이다. 5행 이후 ABC 날짜와 자료의 실제 고시일을 맞춘다. 4행 TODAY는 읽기·쓰기 대상에서 제외한다.
- 증X는 증치세 제외를 뜻한다. 사용자 요청으로 이번에는 입력하지 않는다. 기존 값은 유지하며 임의 세율 계산을 하지 않는다.
- SMM 황산니켈은 원시세와 별개로 `원시세 / 0.2232`인 니켈 환산 시리즈를 연결한다. 공개 홈페이지 기준 단위는 USD/t이며 환산값은 USD/t Ni다. Excel 양식에서 의도한 통화·단위와 맞는지 미리보기에서 확인해야 한다.
- 후보가 없거나 둘 이상이면 빈칸을 추정해 채우지 않고 미연결 목록에 표시한다. 동일 날짜가 5행 이후에 중복되면 전체 반영을 차단한다.
- 원본의 날짜가 양식에 없으면 행을 새로 만들지 않는다. 새 열도 추가하지 않는다. 사용자 수식·텍스트는 덮어쓰지 않는다.

## 회사 Windows 최소 확인

1. 운영 원본 대신 ECM의 TEST 문서를 준비한다. 읽기 전용이면 ECM에서 정식 체크아웃/편집 권한을 확보한다. 보호 해제나 매크로 보안 설정 변경은 하지 않는다.
2. 수집 후 ECM 미리보기를 실행한다. 문서 이름·실제 경로·Excel 창 식별이 연결되고, 기존 금속시세 시트가 선택됐는지 확인한다.
3. Excel의 모든 시트에서 네이티브 행/열 그룹을 8단계까지 펼친다. 수동 숨김이나 시트 보호를 강제로 해제하지 않는다.
4. 미리보기의 열 연결, 실제 날짜, 기존값/입력값, 미연결 열을 검토한다. 증X 열은 미연결로 남는 것이 이번 정상 동작이다.
5. 반영을 승인한다. 미리보기 후 원자료나 문서가 바뀌면 다시 미리보기해야 한다. 변경 셀만 묶어서 쓰고 Excel Save 후 셀을 다시 읽어 검증한다.
6. 4행 TODAY 및 수식, 기존 형식, XLSM(FileFormat 52)·매크로 존재 여부가 유지되는지 확인한다. SaveAs로 XLSX로 바꾸지 않는다.
7. Excel 저장은 서버 체크인 성공을 뜻하지 않는다. ECM에서 저장/체크인 절차 후 다시 열어 실제 서버 반영을 확인한다.

## 검증 경계

사진 양식의 합성 데이터로 헤더 매핑·날짜·중복·수식·증X 제외를 테스트했다. Excel COM 모의 검증으로 그룹 펼치기·XLSM 형식 확인·기존 시트 선택을 확인했다. 회사 내부 ECM/보안 Excel에서 실제 열기·쓰기·체크인은 아직 검증하지 않았다.
