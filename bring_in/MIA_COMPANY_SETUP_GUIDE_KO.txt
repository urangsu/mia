경로 안내 수정: 2026-10-27 KST / 회사 Windows 실행 인수는 미완료

1. TXT와 PY를 매크로 폴더에 넣었다면 이동하지 마세요

현재 파일 위치:
  %APPDATA%\Microsoft\AddIns\vsc\매크로\MIA_SOURCE_CURRENT.txt
  %APPDATA%\Microsoft\AddIns\vsc\매크로\RESTORE_LATEST_SOURCE.py

반입용 날짜 폴더를 만들 필요가 없습니다. 아래 명령은 두 파일의 절대경로를
사용하므로 PowerShell의 현재 폴더에 의존하지 않습니다. 파일을 다른 곳에
넣었다면 $incoming만 실제 TXT/PY가 있는 폴더의 절대경로로 바꾸세요.

새 프로그램 폴더는 날짜 없는 고정 이름 MIA_Collector_Update입니다.
기존 MIA_Collector, MIA_DOM_V4, MIA_ONEFILE, DB, Excel은 삭제/이동/덮어쓰지
않습니다. MIA_Collector_Update도 이미 존재하면 복원은 중단됩니다.
같은 폴더에 계속 덮어쓰는 자동 업데이트 기능은 아닙니다.

복원한 폴더의 사용자용 파일은 아래 다섯 개입니다.
  MIA_Collector.py            : 버전 번호 없는 실행 진입점
  RUN_GUI.cmd                : 화면 실행
  requirements-desktop.txt   : 화면 포함 패키지 설치 목록
  requirements.txt           : 위 목록에서 참조하는 공통 설치 목록
  README_회사.txt             : 지금 읽는 안내의 복원본

내부 소스·테스트·이전 호환 모듈·문서는 app 폴더에 모아두었습니다.
SOURCE_MANIFEST.json은 복원 무결성 목록입니다. app 안의 v3_4/v3_7 파일은
실제 실행되는 내부 모듈이므로 지우지 마세요. 버전별 프로그램을 골라 실행할
필요 없이 MIA_Collector.py 또는 RUN_GUI.cmd만 사용하면 됩니다.
기존 운영 폴더의 파일 정리/삭제는 수행하지 않습니다.

이 수정본의 기본 공개 수집은 로그인 없는 NAVER 일별 시세와 LME Official 표입니다.
LME는 니켈·구리·코발트 Cash/3-month Bid/Ask를 분리하고 Cash Ask·3-month Ask를
금속 누적표에 넣습니다. 주가·지수·시총은 별도 Excel/HTML/PPTX 보고서에만 넣습니다.
사진에 있는 SMM/GFEX, LME Closing/유료 과거 이력까지 구현한 것은 아닙니다.
기존 설정이 있으면 설정 화면에서 수집 출처를 확인하세요. FDR/Yahoo는 선택 사항이며
새 설정의 기본은 꺼짐입니다. '자료·보고서 → 주가·지표 수집'은 NAVER만 실행합니다.
NAVER 시총은 기준 거래일이 없는 실시간 원자료입니다. 비교는 수집일 간 스냅샷이며,
첫날에는 이전 시총 이력이 없습니다. 주가·지수는 실제 두 날짜의 종가를 읽습니다.
LME 고시일과 사이트 갱신일은 구별합니다. 날짜가 오래되면 당일 가격으로 표시하지 않습니다.

필수 파일은 MIA_SOURCE_CURRENT.txt와 RESTORE_LATEST_SOURCE.py 두 개입니다.
RESTORE_LATEST_SOURCE.cmd와 이 안내 TXT는 선택 파일입니다. 날짜를 제거해도
이 네 파일의 이름은 바뀌지 않습니다. TXT는 소스 데이터이며 더블클릭만으로
설치되지 않습니다. 과거 PART/ONEFILE용 복원기를 섞지 마세요.

신뢰하는 저장소의 같은 배포본에서 TXT와 PY를 함께 받으세요:
  https://github.com/urangsu/mia/tree/main/bring_in
Raw/원본으로 다운로드하고 .txt.txt / .py.txt로 이중 저장하지 마세요.
웹페이지 HTML을 저장하거나 TXT를 메신저/Word로 재조합하지 마세요.
TXT는 고정 커밋의 스냅샷이며 미래 main 변경을 자동 반영하지 않습니다.
소스 커밋/파일 개수는 아래 --verify-only 출력으로 확인합니다.
SHA-256은 손상 확인이며 발행자 인증 서명이 아닙니다.

2. 실제 파일 확인 → 무결성 검증 → 새 폴더 복원

일반 PowerShell 창에서 아래 한 블록을 실행합니다. 관리자 권한,
Activate.ps1, 실행 정책 해제, 보안 설정 변경은 필요하지 않습니다.
AddIns 폴더에 둬도 Excel 추가기능으로 자동 설치되는 것은 아닙니다.

---- 명령 시작 ----
$root = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로'
$incoming = $root
$txt = Join-Path $incoming 'MIA_SOURCE_CURRENT.txt'
$restore = Join-Path $incoming 'RESTORE_LATEST_SOURCE.py'
$target = Join-Path $root 'MIA_Collector_Update'
if (-not (Test-Path -LiteralPath $root -PathType Container)) {
    throw '매크로 폴더가 없습니다. 실제 계정/폴더를 확인하세요.'
}
Get-Item -LiteralPath $txt, $restore -ErrorAction Stop | Select-Object Name, Length
py -3 -c "import sys; assert sys.version_info >= (3,10), 'Python 3.10+ required'; print(sys.executable)"
if ($LASTEXITCODE -ne 0) { throw '회사 승인 Python 3.10 이상을 확인하세요.' }
py -3 "$restore" "$txt" --verify-only
if ($LASTEXITCODE -ne 0) { throw 'TXT 검증 실패. 설치를 진행하지 마세요.' }
if (Test-Path -LiteralPath $target) {
    throw '대상 폴더가 이미 있습니다. 삭제하지 말고 기존 복원본을 확인하거나 $target을 다른 새 이름으로 지정하세요.'
}
py -3 "$restore" "$txt" --output "$target"
if ($LASTEXITCODE -ne 0) { throw '복원 실패. 위 오류를 확인하세요.' }
Get-Item -LiteralPath (Join-Path $target 'MIA_Collector.py'), (Join-Path $target 'requirements-desktop.txt') -ErrorAction Stop
---- 명령 끝 ----

기대 위치: %APPDATA%\Microsoft\AddIns\vsc\매크로\MIA_Collector_Update

기존 대상이 있으면 같은 버전의 완전한 복원본인지 확인한 뒤 3번으로 넘어가거나,
별도 복원이 필요할 때 $target을 MIA_Collector_Update_New 등 다른 새 이름으로
정하세요. 이후 $program도 같은 이름을 사용해야 합니다. 원본 삭제는 불필요합니다.

새 RESTORE_LATEST_SOURCE.py는 --output이 없으면 TXT가 실제 있는 폴더 옆의
MIA_Collector_Update로 복원합니다. 새 CMD도 자신의 폴더에 있는 TXT를 검증하고
같은 위치로 복원합니다. 다른 위치에 둔 CMD는 그 옆 TXT를 사용합니다.
오래된 복원 PY/CMD는 기본 위치가 다를 수 있으므로 새 TXT와 함께 교체하세요.
복원기 자체에는 Python 표준 라이브러리만 필요합니다.

3. 새 폴더 전용 가상환경 설치 — 최초 한 번

새 PowerShell 창에서도 실행할 수 있는 독립 블록입니다.
복원 대상을 바꿨다면 $program의 마지막 폴더명도 바꾸세요.

---- 명령 시작 ----
$program = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로\MIA_Collector_Update'
$requirements = Join-Path $program 'requirements-desktop.txt'
Get-Item -LiteralPath $requirements -ErrorAction Stop | Out-Null
$python = Join-Path $program '.venv\Scripts\python.exe'
$venv = Join-Path $program '.venv'
if (-not (Test-Path -LiteralPath $python -PathType Leaf)) {
    if (Test-Path -LiteralPath $venv) { throw '기존 .venv가 불완전합니다. 덮어쓰지 말고 상태를 확인하세요.' }
    py -3 -m venv "$venv"
    if ($LASTEXITCODE -ne 0) { throw '가상환경 생성 실패. 경로/권한/Python 버전을 확인하세요.' }
}
& $python -m pip install -r "$requirements"
if ($LASTEXITCODE -ne 0) { throw '패키지 설치 실패. 회사 승인 저장소/네트워크를 확인하세요.' }
& $python -m pip check
if ($LASTEXITCODE -ne 0) { throw '패키지 의존성 충돌을 먼저 해결하세요.' }
---- 명령 끝 ----

패키지는 이 폴더의 .venv 안에 설치하며 운영 설치본 Python은 변경하지 않습니다.
인터넷 차단 시 해당 Windows/Python에 맞는 승인 wheel 또는 사내 패키지 저장소가
별도로 필요합니다. 소스 TXT에 패키지까지 포함된 것은 아닙니다.
보안 우회/TLS 검증 해제는 하지 마세요. 한글 경로/실행 권한/회사 보안 호환성은
이 Mac의 오프라인 복원 테스트만으로 보장할 수 없습니다.

4. 실행 전 보호 경계 — 설정과 프로필은 계정 공용

새 소스 폴더와 .venv가 있어도 운영 데이터/프로필까지 완전 격리는 아닙니다.
  설정: %LOCALAPPDATA%\FastmarketsCollector\config.json
  전용 Chrome: %LOCALAPPDATA%\FastmarketsCollector\ChromeProfile_9444
  기본 데이터: 사용자 홈\Documents\FastmarketsCollector

기존 data_dir, workbook_path, report_dir가 그대로 적용될 수 있습니다.
GUI 설정을 저장하면 구버전에도 같은 설정이 적용될 수 있습니다. 실제 수집 전
시험용 데이터 폴더, 운영 원본 아닌 승인된 Excel 사본, 별도 보고서 폴더를 먼저
확인하세요. 구버전/기존 예약과 동시에 수집하지 마세요. 복원/설치 명령은 설정,
Chrome 프로필, 기존 FastmarketsCollectorDaily 예약을 수정하거나 등록하지 않습니다.
필요한 예약 중단/운영 전환은 담당자와 조율하며 기존 예약을 임의 삭제하지 마세요.

설정 백업을 원하면 실행 전 로컬에만 사본을 보관하세요. 설정에는 회사 경로가
들어갈 수 있으므로 공개 Git/이슈/외부 채팅에 올리지 마세요. 설정/프로필 복사,
브라우저 전체 종료, 포트 변경은 설치에 필요하지 않습니다.

5. 실행 — 다음날에도 이 블록만 사용

---- 명령 시작 ----
$program = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로\MIA_Collector_Update'
$python = Join-Path $program '.venv\Scripts\python.exe'
$entry = Join-Path $program 'MIA_Collector.py'
Get-Item -LiteralPath $python, $entry -ErrorAction Stop | Out-Null
Set-Location -LiteralPath $program
& $python "$entry"
---- 명령 끝 ----

새 RUN_GUI.cmd도 자신의 폴더의 .venv\Scripts\python.exe를 우선 사용합니다.
.venv가 없을 때만 py -3으로 실행하므로 먼저 3번 설치를 완료하세요.
매번 복원/패키지 재설치할 필요가 없습니다. 예약 등록 후 폴더나 .venv를
옮기지 마세요. 전원이 꺼진 PC를 켜는 기능은 없습니다.

6. 수집 실패 진단 — 설치 성공과 실제 수집 성공은 별개

GUI의 출처/단계와 실제 마지막 오류를 확인하세요. FMB Driver/로그인/작업공간,
공개 HTTP 프록시/TLS/원천 이력, Excel 잠금/권한/출력을 구분합니다.

---- 명령 시작 ----
$program = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로\MIA_Collector_Update'
$python = Join-Path $program '.venv\Scripts\python.exe'
Set-Location -LiteralPath $program
& $python (Join-Path $program 'MIA_Collector.py') --diagnose
---- 명령 끝 ----

기존 Fastmarkets 9444만 확인하며 9222/9337·일반 로그인 Edge에는 간섭하지 않습니다.
위 --diagnose는 기본 연결/소유권 조회입니다. 검증된 기존 9444의 Driver 연결까지
확인하려면 같은 창에서 아래 내부 진단 도구를 명시적으로 실행하세요.

---- 명령 시작 ----
& $python (Join-Path $program 'app\diagnose_windows.py') --driver-check
---- 명령 끝 ----

not_running은 9444가 없다는 뜻이며 로그인 성공이 아닙니다. collector.log,
last_diagnostic.json, 위 진단의 필요한 부분만 계정/회사 경로/비밀정보를 지운 뒤
공유하세요. 쿠키/토큰/비밀번호/전체 프로필/원문 DB/Excel은 보내지 마세요.

예약은 우선 --schedule-status로 조회만 하세요. 새 --schedule 08:30 등록은 동일
이름 FastmarketsCollectorDaily의 기존 작업을 대체할 수 있습니다. 회사 인수 후
운영 전환을 결정한 경우에만 별도로 등록하세요. ECM 승인 쓰기는 자동 수행하지
않습니다. 회사 Windows 실제 수집·보안 Excel·ECM 서버·예약 실기동은 미검증입니다.

7. 개발/인수 담당자용: 복원 소스의 오프라인 회귀

아래 명령은 테스트를 실행합니다. 실수집과 동시에 실행하지 마세요. 테스트는
app 안의 원래 상대경로로 보존되어 있으므로 그 폴더에서 실행해야 합니다.
상용 회사 수집/Excel/ECM 성공을 의미하지 않습니다.

---- 명령 시작 ----
$program = Join-Path $env:APPDATA 'Microsoft\AddIns\vsc\매크로\MIA_Collector_Update'
$python = Join-Path $program '.venv\Scripts\python.exe'
Set-Location -LiteralPath (Join-Path $program 'app')
& $python -m unittest discover -s . -p 'test*.py' -v
---- 명령 끝 ----
